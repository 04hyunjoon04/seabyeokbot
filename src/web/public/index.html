확인 중...
버튼을 누르면 브라우저가 열려요. 치지직 로그인 후 "허용"을 누르면 자동으로 이 앱에 연결돼요. 봇으로 쓰고 싶은 별도 계정이 있다면, 그 계정으로 로그인해서 허용해주세요(그 계정 이름으로 채팅이 나가요).
인가는 한 번만 해두면 돼요 — 이 앱을 30일 안에 한 번씩만 켜두면 만료 전에 자동으로 갱신돼서 다시 인가할 필요가 없어요. 30일 넘게 앱을 아예 안 켜두면 만료돼서 다시 인가해야 해요.

발급된 토큰 (accessToken / refreshToken) ?인가 후 발급된 API 접근 값이에요. 이 값이 유출되면 그 권한(채팅 읽기/쓰기/제재 등)으로 API가 대신 호출될 수 있으니, 절대 다른 사람에게 보여주거나 전달하면 안 돼요.

봇 연결 상태 ?봇이 지금 실제로 치지직 채팅 서버에 연결돼서 채팅을 주고받을 수 있는 상태인지 보여줘요. 빨간불이면 위의 로그인/연동을 먼저 확인해보세요.
