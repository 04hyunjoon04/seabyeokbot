치지직 인가 (공식 로그인) ?봇 전용 계정 아이디/비밀번호를 저장하는 대신, 치지직 공식 로그인 동의 화면에서 방송인(또는 매니저 계정)이 한 번 "허용"을 눌러서 권한을 내주는 방식이에요. 이 앱은 그 권한으로 채팅을 읽고/쓰고 제재해요.

확인 중...
버튼을 누르면 브라우저가 열려요. 치지직 로그인 후 "허용"을 누르면 자동으로 이 앱에 연결돼요. 봇으로 쓰고 싶은 별도 계정이 있다면, 그 계정으로 로그인해서 허용해주세요(그 계정 이름으로 채팅이 나가요).
인가는 한 번만 해두면 돼요 — 이 앱을 30일 안에 한 번씩만 켜두면 만료 전에 자동으로 갱신돼서 다시 인가할 필요가 없어요. 30일 넘게 앱을 아예 안 켜두면 만료돼서 다시 인가해야 해요.

발급된 토큰 (accessToken / refreshToken) ?인가 후 발급된 API 접근 값이에요. 이 값이 유출되면 그 권한(채팅 읽기/쓰기/제재 등)으로 API가 대신 호출될 수 있으니, 절대 다른 사람에게 보여주거나 전달하면 안 돼요.

오버레이 (OBS 브라우저 소스) ?룰렛이 당첨될 때마다 방송 화면에 스핀 애니메이션을 표시하는 기능이에요. 소리는 나오지 않아요. 회전 휠/슬롯머신 스타일은 각 룰렛을 추가·편집할 때 룰렛별로 골라요.

OBS 기준: 소스 추가 → 브라우저 → 위 주소 입력 → 너비 400, 높이 500 정도로 두면 잘 보여요. 배경은 투명하게 나와요. 주소의 포트는 위 Redirect URI와 같이 움직여요, 바꾸려면 Redirect URI를 수정해주세요.
방송 화면(오버레이 페이지)을 열어둔 상태에서 눌러보면 등록된 룰렛 중 하나가 무작위로 재생돼요.

봇 연결 상태 ?봇이 지금 실제로 치지직 채팅 서버에 연결돼서 채팅을 주고받을 수 있는 상태인지 보여줘요. 빨간불이면 위의 로그인/연동을 먼저 확인해보세요.

확인 중...
"로그 확인"을 누르면 새 창이 뜨고, 그 시점부터의 채팅/연결 로그가 실시간으로 쌓여요. 채팅이 연결됐는데도 반응이 없으면 다른 사람 채팅이 [chat]으로 찍히는지 확인해보세요.

데이터 백업 ?유저 명령어, 금칙어, 시스템 명령어 설정, 출석 기록, 룰렛 데이터를 파일 하나로 저장하거나 불러올 수 있어요. 치지직 인가 토큰은 유출 위험이 있어 백업에 포함되지 않아요.

저장 버튼을 누르면 원하는 위치를 직접 골라 파일로 저장돼요. 불러오기를 하면 현재 저장된 유저 명령어·금칙어·출석 기록·룰렛 데이터가 백업 파일 내용으로 전부 덮어써지니, 컴퓨터를 옮기거나 재설치하기 전에 미리 저장해두는 걸 추천해요.
