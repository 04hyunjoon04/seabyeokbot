# 새벽봇 1.0.4

치지직(CHZZK) 방송 채팅에 붙어서 `!명령어`에 반응하는 챗봇입니다. 치지직 공식 Open API로
채팅을 읽고 쓰기 때문에 계정 쿠키를 직접 다루지 않고, 치지직 로그인 화면에서 "허용"만 누르면
연결됩니다. Electron으로 만들어진 데스크톱 프로그램이라 설치 후 아이콘을 실행하면 창 하나가
뜨고, 그 안에서 연동부터 명령어 관리까지 전부 처리할 수 있습니다.

## 기능 소개

**기본 명령어**
방송 시작과 동시에 별도 설정 없이 바로 쓸 수 있는 명령어가 몇 개 들어있습니다.
- `!핑` — 봇이 살아있는지 확인
- `!명령어` — 지금 켜져 있고 공개로 설정된 명령어 목록 출력
- `!업타임` — 현재 방송이 시작된 지 얼마나 지났는지 출력

**커스텀 명령어**
방송인이나 매니저가 채팅창에서 직접 명령어를 만들고 고치고 지울 수 있습니다. 대시보드를
켤 필요 없이 방송 중에 바로 처리할 수 있게 만든 기능입니다.

```
!추가 !환영 어서오세요, $nick님! 즐거운 시간 보내다 가세요.
!추가 !가위바위보 가위!||바위!||보!
!수정 !환영 $nick님 왔구나! 반가워요~
!제거 !환영
```

- 응답 문구를 `||`로 나눠서 여러 개 등록해두면, 명령어가 실행될 때마다 그중 하나가 무작위로
  골라져서 출력됩니다.
- `$nick`(또는 `$name`)을 넣어두면 명령어를 입력한 사람의 닉네임으로 자동 치환됩니다.
- 명령어 이름 앞의 `!`는 붙여도 되고 빼도 똑같이 인식됩니다.
- `!추가`/`!수정`/`!제거`는 기본적으로 매니저 이상만 쓸 수 있고, 이 기준은 대시보드의
  "시스템 명령어" 탭에서 바꿀 수 있습니다.

**명령어별 세부 설정**
대시보드에서 명령어마다 다음을 각각 조절할 수 있습니다.
- 사용 권한 (누구나 / 매니저 이상 / 스트리머 전용)
- 쿨타임 (전체 공용 쿨타임 + 사람별 개인 쿨타임을 따로 지정 가능)
- 켜짐/꺼짐 여부, `!명령어` 목록 노출 여부

**금칙어 자동 제재**
지정한 단어나 문구가 포함된 채팅을 감지해서 자동으로 메시지를 지우거나(블라인드), 일정 시간
채팅을 못 쓰게 제한할 수 있습니다. 매니저 이상 권한을 가진 사람의 메시지는 검사 대상에서
제외됩니다. 이 기능이 동작하려면 봇 계정이 해당 채널에서 "채팅 운영자" 이상 권한을 갖고 있어야
합니다.

**백그라운드 동작**
창을 X로 닫아도 봇은 바로 꺼지지 않고, 완전히 종료할지 백그라운드에서 계속 돌게 할지 먼저
물어봅니다. 백그라운드를 선택하면 작업표시줄이나 트레이 아이콘으로 언제든 창을 다시 열 수
있고, 그 선택을 다음부터 기억하게 체크해둘 수도 있습니다.

## 시작하기 전에 준비할 것

1. **치지직 개발자 센터** (https://developers.chzzk.naver.com/) 에서 애플리케이션을 등록하고
   Client ID / Client Secret을 발급받습니다.
2. 애플리케이션 설정의 **Redirect URI**에 아래 값을 등록합니다 (프로그램의 기본 포트 기준).

   ```
   http://localhost:8090/callback
   ```

3. 애플리케이션의 **API 권한(scope)**에서 아래 항목을 체크합니다.
   - 채팅 메시지 조회 / 채팅 메시지 쓰기 / 채팅 공지 쓰기
   - 활동제한 조회 / 활동제한 쓰기
   - 채널 정보 조회 (관리 화면에 채널 이름·프로필 사진을 표시하는 용도)

## 처음 실행하기

1. 설치된 프로그램을 실행하면 창이 뜨고, 왼쪽 위 계정 영역에서 **"계정 연동"** 화면으로 들어갈
   수 있습니다.
2. 위에서 발급받은 Client ID / Client Secret / 채널 ID를 입력하고 저장합니다.
3. **"치지직 인가 페이지 열기"** 버튼을 누르면 브라우저가 열립니다. 봇으로 사용할 계정(방송인
   본인 계정이거나, 매니저로 등록해 둔 별도 계정)으로 로그인해서 "허용"을 누르면 자동으로
   프로그램에 연결되고 채팅에 참여합니다.
4. "봇 연결 상태"에 초록불이 뜨면 방송 채팅창에 `!핑`을 입력해 "퐁!" 응답이 오는지 확인합니다.

봇은 인가를 완료한 계정의 이름으로 채팅에 참여합니다. 방송인 본인 계정으로 인가했다면 방송인
이름으로, 매니저 계정으로 인가했다면 그 매니저 이름으로 채팅이 올라갑니다.

## 매니저 권한 등록

`!추가` 같은 관리 명령어와 금칙어 제재(메시지 삭제, 임시 제한) 기능을 정상적으로 쓰려면, 봇으로
사용할 계정이 해당 채널의 치지직 스튜디오 > 권한 관리에서 **채팅 운영자(또는 채널 관리자) 이상**
으로 등록되어 있어야 합니다.

## 창 닫기 / 백그라운드 동작

창의 X 버튼을 누르면 매번 "완전히 종료할지 / 백그라운드에서 계속 실행할지" 물어봅니다.
"백그라운드에서 계속 실행"을 선택하면 창만 최소화되고 봇은 계속 채팅에 참여한 상태로
남습니다. 작업표시줄이나 트레이(알림 영역) 아이콘을 눌러 언제든 다시 열 수 있고, 트레이
아이콘 우클릭 메뉴에서 완전히 종료할 수도 있습니다. 물어보는 창 오른쪽 아래의 "다음부터 이
설정 기억하기"를 체크해두면, 다음부터는 같은 선택이 자동으로 적용되고 다시 묻지 않습니다.

## 윈도우 11 사용자

윈도우 11에서 실행하면 창 배경에 윈도우 11 기본 앱들과 비슷한 반투명(Mica) 효과가 자동으로
적용됩니다. 윈도우 10에서는 이 효과가 지원되지 않아 기존과 동일한 배경으로 표시됩니다. 별도
설정은 필요 없습니다.

## 데이터는 어디에 저장되나요

계정 정보(Client ID/Secret, 로그인 토큰), 커스텀 명령어, 금칙어, 명령어별 설정 같은 데이터는
전부 설치 폴더가 아니라 `%APPDATA%\saebyeokbot` 폴더에 저장됩니다. 그래서 새 버전을 내려받아
덮어 설치하거나 실행 파일만 새로 바꿔치기해도 기존 데이터가 사라지지 않습니다.

## 알아두어야 할 점

- **인가는 30일마다 갱신이 필요합니다.** 프로그램이 켜져 있는 동안은 자동으로 갱신되지만, 30일
  넘게 프로그램을 한 번도 켜지 않으면 인가가 만료되어 "계정 연동" 화면에서 다시 인가를 진행해야
  합니다.
- **영구 차단은 지원하지 않습니다.** 지원되는 제재는 메시지 삭제(블라인드)와 임시 제한 두
  가지뿐입니다.
- 채팅 메시지는 한 번에 최대 100자까지 전송됩니다.
- 발급된 로그인 토큰은 이 컴퓨터에만 저장되며, 외부로 전송되지 않습니다. "계정 연동" 화면에서
  "값 보기" 버튼을 눌러야만 실제 값이 보이도록 가려져 있습니다 — 이 값이 유출되면 그 계정으로
  로그인한 것처럼 행동할 수 있으니 공유하지 마세요.
